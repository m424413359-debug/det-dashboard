# تحضير الدولينجو — لوحة تعمل بدون إنترنت

تطبيق أندرويد لتنظيم خطة تحضير امتحان Duolingo English Test خلال 4 أسابيع. كل شيء يعمل أوفلاين، والتقدّم محفوظ على الجوال.

## التنزيل

آخر نسخة دائماً على هذا الرابط:

**https://github.com/m424413359-debug/det-dashboard/releases/latest/download/det-prep.apk**

1. افتح الرابط من الجوال (مرة وحدة وأنت أونلاين).
2. افتح الملف ووافق على «التثبيت من مصادر غير معروفة» إذا طلب.
3. بعد التثبيت، التطبيق ما بيحتاج إنترنت نهائياً.

التحديثات الجاية بتنثبّت فوق النسخة القديمة وبتحافظ على تقدّمك. للاحتياط، انسخ نسختك الاحتياطية من الإعدادات قبل أي تحديث.

## الأقسام

- **اليوم:** أفضل علامة على مسطرة من 160 مع منطقة الهدف 110–120، العد التنازلي، جلسات آخر أسبوع، مهام الأسبوع الحالي، وقائمة «جاني نت».
- **الخطة:** 5 مراحل (التجهيز + 4 أسابيع)، كل مهمة بخطواتها وملاحظاتك، تصفية حسب الحاجة للإنترنت، وإضافة مهام خاصة.
- **المؤقّت:** الساعة اليومية بأجزائها الأربعة (10/20/20/10) مع صوت بنهاية كل جزء.
- **دفتري:** العلامات مع منحنى، دفتر الأخطاء، كلماتي كبطاقات مراجعة، ومسوّدة «للتصحيح».
- **المكتبة:** شكل الامتحان، القوالب، الاستراتيجيات، جدول المحاكاة، مواضيع وأسئلة عشوائية بمؤقت، وقائمة جاهزية يوم الامتحان.

## البناء

الملف `.github/workflows/build-apk.yml` يبني الـ APK تلقائياً مع كل تعديل على `main` باستخدام Capacitor، وينشره كـ Release باسم `latest`. واجهة التطبيق في مجلد `www/` (HTML و CSS و JavaScript بدون أي مكتبات خارجية).
